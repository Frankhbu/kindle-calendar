# Kindle 日历

一个用来生成 Kindle 锁屏/壁纸日历的静态页面：左侧选月份、字体、下载，右侧是 758 × 1024 的日历画布，截图只截右侧这一块。

左边是操作面板，右边是预览画布，两边各占页面一半。

## 打开方式

直接用浏览器打开 `calendar.html` 即可，不需要安装依赖、不需要起服务。

## 目录结构

```
calendar.html              页面本体（结构 + 样式 + 逻辑，全部内联）
vendor/html2canvas.min.js  截图库（本地副本，不依赖 CDN）
vendor/lunar.min.js        农历 / 节气 / 干支 / 生肖计算库（MIT，纯本地计算）
vendor/jszip.min.js        导出全年时打包 zip（MIT）
data/holidays.js           法定节假日与调休安排（行政数据，按年份人工维护）
data/poems.js              底部诗句 / 名言（按「诗句集」组织，每月一句）
fonts/                     自定义字体目录，篆体放这里（见 fonts/README.md）
```

## 项目约定

1. **纯静态实现**：只用 HTML / CSS / 原生 JS，不引入构建工具、不依赖服务端、不出现 Node 运行时逻辑。
2. **不接需要登录授权的接口**：需要外部数据时，优先选无需鉴权的公开接口，或直接把数据写进页面里的静态常量（目前节假日就是这么维护的）。
3. **第三方依赖本地化**：能用本地文件就不用 CDN，保证断网也能用；仓库里 `vendor/` 就是这个用途。
4. **截图区域固定**：日历画布始终是 758 × 1024（Kindle 竖屏），预览缩放只影响显示，不影响导出。

## 已实现的功能

- 月份切换：上一月 / 下一月、键盘 ← →、年份直接跳转、「今天」一键回到当前月；打开页面默认当前月
- 农历日期、二十四节气、公历/农历节日、干支纪年、生肖年全部本地实时计算，无写死数据
- 普通周末、法定节假日统一加灰底；调休上班日标记「班」；放假 / 调休数据来自 `data/holidays.js`
- 日期格子为正方形，最后一行若全是下月日期则整行不渲染
- 画布底部固定一行当月古诗，国画落款式排版（诗句居中 + 落款右对齐），填掉格子下方的留白；诗句、落款字号可分别调整，诗句集可在左侧切换
- 三个区域（年月 / 星期表头 / 日期与农历）可分别设置字体和字号，诗句与落款可单独调字号；农历字号按比例跟随日期字号；「休 / 班」徽标固定 12px，不随设置变化
- 字体切换：黑体 / 宋体 / 楷体 / 篆体（篆体需自备字体文件）
- 截图导出：只导出当月，或一键导出当前年份 12 个月并打包成 zip（每张 758 × 1024 PNG，Kindle 原尺寸）；导出期间锁定月份和排版控件，保证 12 张图风格一致

## 节假日数据维护

`data/holidays.js` 里按年份存放放假和调休安排，2026 年（按
[国办发明电〔2025〕7 号](https://www.gov.cn/zhengce/content/202511/content_7047090.htm)）和 2027 年都已录入：

| 年份 | 放假天数 | 调休上班天数 |
|---|---|---|
| 2026 | 33 | 6 |
| 2027 | 29 | 5 |

新增下一年时，在 `window.HOLIDAY_DATA` 里加一个年份即可，结构照抄现成的某年：

```js
2028: [
    { name: '元旦', rest: ['2028-01-01'], work: [] },
    ...
]
```

页面左上角会提示当前年份的数据状态（「已加载 xx 年调休安排」/「xx 年暂无调休数据」）。

## 诗句数据维护

`data/poems.js` 里按「诗句集」组织，每集 12 条，按月取用，和年份无关：

```js
window.POEM_DATA = {
    classic: { label: '古诗 · 十二月', months: { 1: { text: '…', sig: '…' }, … } },
    sayings: { label: '名句 · 十二月', months: { … } }
};
```

想加一套「12 位名人的名言」时，照着加一个 key（比如 `quotes`）即可，
左侧「诗句」面板的下拉框会自动多出一项，不用改 `calendar.html`。
